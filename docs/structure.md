# Структура проекта

```
Dragon-Park-Builder/
│
├── docs/                    # Документация
│   ├── GDD.md                 # Game Design Document
│   ├── roadmap.md             # Дорожная карта
│   └── structure.md           # Этот файл
│
├── assets/                  # Ресурсы (арт, звук, модели)
│   ├── dragons/               # Спрайты/модели драконов
│   ├── ui/                    # Интерфейс
│   ├── environment/           # Окружение парка
│   └── audio/                 # Музыка и звуки
│
├── src/                     # Исходный код (зависит от движка)
│   ├── core/                  # Основные системы
│   ├── dragons/               # Логика драконов
│   ├── park/                  # Строительство и управление парком
│   ├── battles/               # Битвы
│   ├── minigames/             # Мини-игры
│   └── ui/                    # Код интерфейса
│
├── tests/                   # Тесты
│
└── README.md
```

Эта структура будет адаптирована под выбранный движок.
