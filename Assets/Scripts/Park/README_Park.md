# Система парка и размещения зданий

## Что есть

- **Building.cs** — базовый класс здания (тип, размер, стоимость)
- **ParkGrid.cs** — сетка парка (проверка места, размещение, удаление)
- **BuildingPlacer.cs** — размещение зданий мышкой (клавиша B для начала размещения)

## Как использовать

1. Создай пустой объект с `ParkGrid`
2. Создай Ground с коллайдером и нужным Layer
3. Добавь `BuildingPlacer`, назначь ParkGrid и префаб здания
4. Нажми **B**, наведи мышкой и кликни ЛКМ для размещения
