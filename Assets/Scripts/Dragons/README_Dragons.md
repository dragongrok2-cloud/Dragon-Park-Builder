# Базовая система дракона

## Что уже есть

### `DragonStage.cs`
Перечисление стадий:
- Egg (Яйцо)
- Baby (Малыш)
- Young (Юный)
- Adult (Взрослый)
- Legendary (Легендарный)

### `Dragon.cs`
Основной компонент дракона. Добавь его на GameObject дракона.

**Возможности:**
- Имя и элемент
- Стадии роста с прогрессом
- Голод и счастье (постепенно уменьшаются)
- Методы:
  - `Feed(float foodValue)` — покормить
  - `Pet()` — погладить
  - `AddGrowth(float amount)` — добавить прогресс роста
  - `AddExperience(float exp)` — опыт и уровни
- Свойства:
  - `CanFly` — можно ли летать
  - `CanBattle` — готов ли к битве
- События: `OnFed`, `OnPetted`, `OnStageChanged`, `OnLevelUp`

## Как использовать

1. Создай GameObject дракона
2. Добавь компонент `Dragon`
3. Из UI или других скриптов вызывай:
   ```csharp
   dragon.Feed(30f);
   dragon.Pet();
   ```
4. Подписывайся на события для обновления интерфейса.
