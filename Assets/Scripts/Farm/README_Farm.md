# Система фермы и еды

## Что есть

- **FoodItem.cs** — данные о еде (название, восстановление голода, стоимость, время роста)
- **FarmPlot.cs** — грядка: Empty → Growing → Ready
- **FoodManager.cs** — инвентарь еды + покупка за золото

## Как использовать

1. Добавь `FoodManager` на сцену (DontDestroyOnLoad)
2. Создай грядки с компонентом `FarmPlot`
3. Вызывай `plot.Plant(foodItem)` чтобы посадить
4. Когда Ready — `plot.Harvest()` возвращает еду
5. Корми дракона через `dragon.Feed()` + используй еду из инвентаря

Позже можно сделать ScriptableObject для еды и красивый UI инвентаря.
