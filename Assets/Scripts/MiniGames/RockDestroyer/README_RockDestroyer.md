# Мини-игра: Разрушение камней (Rock Destroyer)

Третий прототип мини-игры.

## Суть
Кликай по камням, чтобы разрушать их. Набери нужное количество очков до конца времени.

## Как настроить

1. Создай 2D-сцену
2. **Камень (Prefab)**:
   - Sprite Renderer
   - Collider2D
   - Скрипт `Rock`
3. **Менеджер** + UI (счёт, таймер, панели)
4. **Spawner** с префабом камня

Управление: **Левая кнопка мыши** по камням.
